# Advanced Patterns Pro

Advanced Patterns Pro loads block patterns from a `patterns` subdirectory. Each PHP file inside `patterns` should return a single PHP array describing one pattern. This allows you to manage patterns as separate files and easily add/remove patterns.

FEATURES:
- Adds an extensive library of custom patterns to the block editor
- All patterns use native WordPress blocks
- Lightweight, great for SEO and page load speeds
- Adds ID and REL fields to each block which can be helpful for developers to customize the design and interactive features of blocks

INSTALLATION:
1. Copy the `advanced-patterns-pro` folder into `wp-content/plugins/`.
2. Activate the plugin in the WordPress admin.
3. Create a new page (or edit an existing page)
4. In the block editor, click the (+) icon in the toolbar, click Patterns, add a pattern
5. Repeat to add multiple designs to your page and save.
6. Check out our docs for more info on how to customize blocks and patterns once you've added them to your page
7. Do your happy dance. Tell your friends.
