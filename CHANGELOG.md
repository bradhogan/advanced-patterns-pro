# Changelog

All notable changes to Advanced Patterns Pro will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project uses version numbers in the format `MAJOR.MINOR.PATCH`.

---

## [1.0.0] - 2026-08-05

### Added
- Initial release of Advanced Patterns Pro
- 60 block patterns across multiple categories: heroes, headers, footers, grids, testimonials, pricing, FAQs, CTAs, queries, courses, authors, and more
- Compiled JS (`build/appro.js`, `build/appro-min.js`) and CSS (`build/styles.css`) assets
- SCSS source file (`build/styles.scss`) for style customization
- Image and SVG asset library (`images/`)
